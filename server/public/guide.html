포커 플레이어 노트를 기록하고 어디서든 확인하세요

Chrome 익스텐션 설치
poker-notes.zip 다운로드
1
위 버튼으로 zip 다운로드
위의 버튼을 클릭하여 poker-notes.zip 파일을 다운로드합니다.
2
압축 풀기
원하는 위치에 zip 파일의 압축을 풀어주세요. 폴더 안에 manifest.json 파일이 있어야 합니다.
3
Chrome 확장 프로그램 페이지 열기
Chrome 주소창에 chrome://extensions 를 입력하고 Enter를 누르세요.
4
개발자 모드 켜기
우측 상단의 개발자 모드 토글을 켜세요.
5
"압축해제된 확장 프로그램을 로드합니다" 클릭
좌측 상단 버튼을 클릭하고, 2단계에서 압축을 풀었던 폴더를 선택합니다.
6
포커 테이블 접속
play.pokerlulu.com 에 접속하면 플레이어 위에 메모 버튼이 자동으로 표시됩니다.
Tip — 익스텐션은 포커 테이블 페이지에서만 동작합니다. 플레이어 위의 연필 아이콘을 클릭하면 노트를 작성/수정할 수 있습니다.
참고 — 노트 위치가 10초에 한번씩 최적화됩니다. 적절하게 화면 창 사이즈를 조절하세요.
Kiwi Browser에서 익스텐션 설치
왜 Kiwi Browser? — Android의 일반 Chrome은 익스텐션을 지원하지 않습니다. Kiwi Browser는 Chrome 기반이면서 PC용 Chrome 익스텐션을 그대로 설치할 수 있는 무료 브라우저입니다.
1
Kiwi Browser 설치
Google Play 스토어에서 Kiwi Browser를 검색하여 설치합니다.
2
익스텐션 zip 다운로드
Kiwi Browser에서 아래 버튼을 탭하여 다운로드합니다.
poker-notes.zip
3
확장 프로그램 페이지 열기
Kiwi Browser 주소창에 kiwi://extensions 를 입력합니다.
4
개발자 모드 켜기
우측 상단의 Developer mode 토글을 켜세요.
5
zip 파일로 설치
+(from .zip/.crx/.user.js) 버튼을 탭하고, 다운로드한 zip 파일을 선택합니다.
6
포커 테이블 접속
Kiwi Browser에서 play.pokerlulu.com 에 접속하면 PC와 동일하게 사용할 수 있습니다.
Tip — Kiwi Browser를 기본 브라우저로 설정하면 포커 앱에서 링크를 열 때 자동으로 익스텐션이 적용됩니다.
또는 웹앱으로 사용
1
웹앱 열기
아래 버튼을 탭하면 노트 검색/작성 웹앱이 열립니다. 테이블 오버레이는 없지만, 닉네임으로 빠르게 노트를 조회할 수 있습니다.
웹앱 열기
웹앱으로 사용 (PWA)
iOS에서는 Chrome 익스텐션을 사용할 수 없습니다. 대신 웹앱을 홈 화면에 추가하면 앱처럼 사용할 수 있습니다. PC 익스텐션과 같은 데이터를 공유합니다.
1
Safari에서 웹앱 열기
아래 버튼을 탭하거나, Safari에서 이 사이트의 메인 페이지로 이동합니다.
2
공유 버튼 탭
Safari 하단의 공유 버튼 (□↑ 모양)을 탭합니다.
3
"홈 화면에 추가" 선택
공유 메뉴에서 홈 화면에 추가를 탭하고, "추가"를 누르세요.
4
앱처럼 사용
홈 화면에 생긴 아이콘을 탭하면 전체화면으로 열립니다. 닉네임 검색 → 노트 조회/작성이 가능합니다.
웹앱 열기
참고 — 웹앱은 테이블 위에 오버레이되지 않지만, 포커 플레이 중 닉네임으로 빠르게 노트를 검색하고 메모를 남기는 용도로 사용할 수 있습니다.
